# Handoff: Manga Translator

## สถานะ (2026-10-26)
MVP ครบ pipeline ทีละหน้า ภาษาต้นฉบับญี่ปุ่นและอังกฤษ แปลด้วย Ollama (ค่าเริ่มต้น Gemma-4-E4B Uncensored Q4_K_M ซึ่งแปลหน้าจริงได้แม่นกว่า qwen3.5:4b และ Qwen3.5-9B Uncensored) มี UI หน้าต่างเดียวและ CLI
pytest ผ่าน 24 ข้อ (รวม Ollama จริงและ LaMa บน GPU) ส่วน `tools/ui_smoke.py` เปิดหน้าต่างจริง รันครบ 5 ขั้น แก้คำแปล แล้ว Undo/Redo ได้

## โครงสร้าง
- `manga_translator/core/`: project (PageDoc/Region + page.json), detect, ocr, translate, inpaint, typeset, pipeline (Models โหลดทีละตัว + 5 ขั้น), settings
- `manga_translator/ui/`: main_window, canvas (กล่อง + แปรง mask), region_panel, settings_dialog, worker (QThread)
- `models/` ไม่เข้า git ดาวน์โหลดด้วย `tools/download_models.py` (hash อยู่ใน manifest.json)

## ตัวเลขที่วัดได้ (RTX 5060 8GB, หน้าสังเคราะห์ 900×1300)
- detect 1.3 วิ (ONNX บน CPU), manga-ocr โหลดครั้งแรก ~20 วิ อ่าน 3 กล่องเร็ว, Ollama ครั้งแรก ~80 วิ (โหลดโมเดล) ครั้งต่อไป ~3 วิ, clean 0.1 วิ, typeset ~1 วิ
- VRAM ของ torch สูงสุด 0.44 GB (ไม่รวม Ollama)

## จุดที่ต้องระวัง
- `opencv-python` (ที่ rapidocr ดึงมา) ชนกับ `opencv-python-headless`/PySide6 ให้ติดตั้งเฉพาะตัว headless
- `cv2.imread` เปิด path ที่มีอักษรไทย/ญี่ปุ่นไม่ได้ ให้ใช้ `project.imread/imwrite` (np.fromfile + imdecode)
- ห้ามส่ง Thai ที่มีเครื่องหมายวรรคตอนให้ newmm ทั้งก้อน (`เหรอ...` จะกลายเป็น `เห|รอ.`) ใน `typeset.tokenize` จึงแยกส่วนที่เป็นไทยออกก่อน
- คำพูดภาษาปากใส่เพิ่มได้ที่ `THAI_EXTRA_WORDS`
- ทางสำรองของ OCR อังกฤษ (ตอนไม่มี mask) ยังใช้ตัวหาบรรทัดของ RapidOCR ซึ่งต้องเติมขอบ 20px รอบภาพที่ crop ไม่งั้นคำจะแตก
- ห้ามต่อ signal จาก thread AI เข้า lambda เพราะ lambda จะรันบน thread นั้นและไปแตะ widget จนพังใน Qt6Core.dll ให้ต่อเข้าเมธอดของหน้าต่างแทน
- `bubble_rects` ใช้ flood fill จากกลางกล่องบนภาพ cleaned ถ้าพื้นที่เกิน 25% ของหน้าหรือกว้าง/สูงเกือบเต็มหน้า จะถือว่ารั่วออกนอกบอลลูนและใช้กล่องเดิมแทน

## คุณภาพบนหน้าจริง (2026-10-26, หน้ามังงะอังกฤษ 1200×1761 ที่ผู้ใช้ให้มา)
- OCR อังกฤษ: แยกบรรทัดเองจาก mask ของ comic-text-detector แล้วให้ `en_PP-OCRv3_rec_infer.onnx` อ่านทีละบรรทัด ความผิดพลาดระดับตัวอักษรลดจาก 12.9% เหลือ 2.9% (เดิม RapidOCR หาบรรทัดเองแล้วทำบรรทัดหายและคำติดกัน การขยายภาพหรือปรับ threshold ของ RapidOCR ทำให้แย่ลง)
- บอลลูนที่มีข้อความสองกลุ่มวางเหลื่อมกัน จะถูกแยกคอลัมน์ก่อนแบ่งบรรทัด (`text_lines`)
- ตัวตรวจจับใช้เกณฑ์ `CONF_THRESH` 0.25 (ที่ 0.4 พลาดบอลลูนจริงที่ได้ score 0.31 และลดถึง 0.2 ก็ไม่มีกล่องหลอกเพิ่มบนหน้านั้น)
- จัดวางข้อความด้วย `bubble_rects`: สี่เหลี่ยมที่ขยายออกจากกลางบอลลูน (ไม่ชิดหนามของบอลลูนทรงหนาม) มีขนาดตัวอักษรต่ำสุดตามขนาดหน้า (`min_size_for`) ถ้าใส่ไม่พอจะเลือกให้ข้อความล้นออกด้านข้างพร้อมขอบขาว แทนการตัดกลางคำ
- ตัวแปลได้ป้าย `"short": true` สำหรับบอลลูนสั้น
- การวัดผลใช้หน้าของผู้ใช้ที่ `.scratch/` (ไม่เข้า git เพราะเป็นงานที่มีลิขสิทธิ์) เทสต์ใน repo ใช้ข้อความที่แต่งขึ้นเองเท่านั้น
