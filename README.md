# Manga Translator

โปรแกรม Windows สำหรับแปลมังงะในเครื่อง ทำงานทีละขั้นและแก้ไขได้ทุกขั้น:

1. **ตรวจจับข้อความ**: ใช้ comic-text-detector หากล่องข้อความและพื้นที่ตัวอักษร
2. **อ่านข้อความ**: ภาษาญี่ปุ่นใช้ manga-ocr (อ่านแนวตั้งได้) ภาษาอังกฤษใช้ RapidOCR
3. **แปล**: ใช้โมเดลใน Ollama ส่งทั้งหน้าในคำขอเดียวเพื่อให้โมเดลเห็นบริบท และรองรับอภิธานศัพท์
4. **ลบคำ**: บอลลูนพื้นเรียบใช้การเติมสีพื้น พื้นที่มีลายใช้ LaMa บน GPU โดยเปลี่ยนเฉพาะพิกเซลในพื้นที่ลบ
5. **ใส่คำแปล**: ตัดคำไทยด้วย pythainlp และไม่ตัดกลางคำ ปรับขนาดฟอนต์ให้พอดีบอลลูนอัตโนมัติ

## ติดตั้งในเครื่องใหม่
ต้องมี: Windows 10/11, [Python 3.12](https://www.python.org/downloads/), [Git](https://git-scm.com/download/win) และ [Ollama](https://ollama.com/download) ส่วนการ์ดจอ NVIDIA ไม่บังคับ แต่ถ้ามีจะลบคำบนพื้นที่มีลายได้เร็วกว่ามาก

```
git clone https://github.com/VAQELUNORA/manga-translator.git
cd manga-translator
setup.bat
```
`setup.bat` จะทำให้ทั้งหมด:
- สร้าง `.venv`
- ติดตั้ง PyTorch (ถ้าเจอการ์ด NVIDIA ใช้รุ่น CUDA 12.8 ถ้าไม่เจอใช้รุ่น CPU)
- ติดตั้งไลบรารี
- ดาวน์โหลดโมเดล AI ราว 750 MB ลง `models/` และตรวจ hash
- ถามว่าจะดึงโมเดลแปลของ Ollama เลยไหม (ราว 6.3 GB)

ถ้ายังไม่ได้ดึงโมเดลแปล ใช้คำสั่งนี้ทีหลังได้:
```
ollama pull hf.co/HauhauCS/Gemma-4-E4B-Uncensored-HauhauCS-Aggressive:Q4_K_M
```
อัปเดตเป็นเวอร์ชันล่าสุด: `git pull` แล้วรัน `setup.bat` อีกครั้ง (ส่วนที่ติดตั้งแล้วจะถูกข้าม)

การตั้งค่า (`settings.json`) ไฟล์งาน (`work/`) และโมเดล ไม่ได้อยู่ใน git แต่ละเครื่องจึงมีชุดของตัวเอง

## เปิดโปรแกรม
ดับเบิลคลิก `Start MangaTranslator.bat` แล้วลากโฟลเดอร์ ภาพ หรือไฟล์ ZIP/CBZ/RAR/CBR/7Z มาวางในหน้าต่าง (หรือกด **📂 เปิดโฟลเดอร์ภาพ** / **📦 เปิดไฟล์บีบอัด**) จากนั้นกด **▶ ทำทั้งหมด** (F5) หรือกดทีละขั้น 1–5
ต้องเปิด Ollama ไว้ก่อน (โมเดลเริ่มต้นคือ Gemma-4-E4B Uncensored `hf.co/HauhauCS/Gemma-4-E4B-Uncensored-HauhauCS-Aggressive:Q4_K_M` ดึงด้วย `ollama pull` ชื่อนี้ เปลี่ยนได้ใน ⚙ ตั้งค่า)

- **ลากวาง:** โฟลเดอร์จะเปิดเป็นตอน ไฟล์บีบอัดจะถูกแตกไปที่ `work/_imported/<ชื่อไฟล์>/` แล้วเปิด (หน้าในโฟลเดอร์ย่อยเรียงตามลำดับ) ส่วนภาพที่ลากมาตอนมีตอนเปิดอยู่ จะถูกคัดลอกเข้าตอนนั้น (`work/<ตอน>/_added/`) ถ้ายังไม่ได้เปิดตอน จะสร้างตอนใหม่ให้ ทั้งหมดใช้วิธีคัดลอก ไม่แก้ไฟล์ต้นฉบับ ส่วน RAR/CBR/7Z ใช้ `tar.exe` ที่มากับ Windows 10/11
- ลากโฟลเดอร์หรือไฟล์บีบอัดไปวางบนไอคอน `Start MangaTranslator.bat` ก็เปิดได้เลย
- **แก้คำแปล:** เลือกกล่องทางขวาแล้วพิมพ์ ภาพจะอัปเดตเอง กล่องที่แก้เองจะถูก 🔒 ล็อก และขั้นอัตโนมัติจะไม่เขียนทับ
- **เรียงหน้า:** ช่อง "เรียง" เหนือรายการหน้า เลือกได้ว่าจะเรียงตามชื่อ (เลขในชื่อเรียงแบบตัวเลข p2 มาก่อน p10) วันที่แก้ไข หรือขนาดไฟล์ ปุ่ม ↓/↑ สลับทิศ หรือลากหน้าในรายการเพื่อเรียงเอง (จำลำดับไว้ใน `work/<ตอน>/order.json`)
- **ทำหลายหน้า:** Ctrl/Shift+คลิกเลือกหลายหน้า แล้วกด "▶ ทำหน้าที่เลือก" (F5) หรือ "▶▶ ทำทุกหน้า" ระบบจะทำตามลำดับในรายการ ถ้าหน้าไหนพังจะข้ามไปหน้าถัดไป แล้วสรุปตอนจบพร้อมปุ่ม "ลองใหม่เฉพาะหน้าที่พัง" ติ๊ก "ข้ามหน้าที่ทำครบแล้ว" ไว้ได้ ในรายการ ✓ = ทำครบ, ⚠ = พัง, 💾 = เซฟอัตโนมัติแล้ว
- **เซฟอัตโนมัติ:** ตั้งใน ⚙ ตั้งค่า → การเซฟ (โฟลเดอร์หลัก คำนำหน้า โดย `{ตอน}` คือชื่อโฟลเดอร์ต้นฉบับ เลขเริ่ม จำนวนหลัก และชนิด PNG/JPG/WEBP) ผลลัพธ์จะไปอยู่ที่ `<โฟลเดอร์หลัก>/<ตอน>/<คำนำหน้า><เลข>` ทุกครั้งที่ภาพเปลี่ยน โดยเลขตามลำดับในรายการ ถ้าเรียงใหม่ ไฟล์จะถูกเซฟใหม่ตามเลขใหม่ โปรแกรมไม่เขียนทับหรือลบไฟล์ที่ไม่ได้เขียนเอง
- **เซฟหลายหน้า (Ctrl+S):** เลือกหน้า คำนำหน้า เลข และชนิดไฟล์ ดูตัวอย่างชื่อทุกไฟล์ก่อนเซฟ และถ้ามีชื่อซ้ำจะถามก่อนเขียนทับ
- **ตัดบรรทัดเอง:** กด Enter ในช่องคำแปลเพื่อขึ้นบรรทัดใหม่ ถ้าเลือก "ตัดเฉพาะที่กด Enter" โปรแกรมจะใช้บรรทัดตามที่พิมพ์ทุกประการ และย่อตัวอักษรจนบรรทัดยาวสุดพอดีกรอบ
- **ย้ายคำแปล:** กดโหมด "ย้ายข้อความ" แล้วลากกรอบสีส้มไปวางตรงไหนก็ได้ ลากมุมขวาล่างเพื่อปรับพื้นที่ (ขนาดตัวอักษรปรับตาม) กด "วางข้อความอัตโนมัติ" เพื่อกลับไปให้โปรแกรมจัดเอง
- **ย้าย/ปรับกล่อง:** ใช้โหมด "เลือก/ย้าย" ลากกล่อง หรือลากมุมขวาล่างเพื่อปรับขนาด ส่วน "+ กล่อง" ใช้ลากสร้างกล่องใหม่
- **ลบตัวอักษรไม่หมด:** ใช้ "ระบายส่วนที่จะลบ" หรือ "ยางลบ" แล้วกด "4. ลบคำ" อีกครั้ง
- **ระบายสีเอง:** โหมด "🖌 ระบายสี" ระบายสีทับภาพด้วยมือ เช่น ปิดรอยที่ลบไม่หมดหรือเติมพื้นบอลลูน กดช่องสีเพื่อเลือกสี กด "ดูดสี" หรือ Alt+คลิกเพื่อใช้สีจากภาพ ขนาดแปรงใช้แถบเดียวกัน ส่วน "ลบสี" ใช้ลบสีที่ระบายไว้ สีอยู่ใต้คำแปลเสมอ เก็บแยกใน `paint.png` จึงไม่หายเมื่อรันขั้นตอนซ้ำ และย้อนกลับได้ทั้ง Ctrl+Z และประวัติของหน้า
- **ย้อนกลับ:** Ctrl+Z / Ctrl+Y
- **ประวัติของหน้า (Ctrl+H):** โปรแกรมเก็บสภาพหน้าไว้ก่อนทุกครั้งที่รันขั้นตอน รีเซ็ต หรือคืนค่า ถ้าผลใหม่แย่กว่าเดิม เปิดประวัติแล้วเลือกคืนค่าได้ (ค่าเริ่มต้นเก็บ 10 รายการต่อหน้า ปรับได้ในตั้งค่า เก็บแบบ hard link ไฟล์ที่ไม่เปลี่ยนจึงไม่กินพื้นที่ซ้ำ)
- **รีเซ็ตเป็นต้นฉบับ:** เมนู แก้ไข หรือคลิกขวาที่รายการหน้า ล้างกล่อง คำแปล และภาพที่ลบคำแล้วของหน้าที่เลือก (เลือกหลายหน้าได้) ภาพต้นฉบับไม่ถูกแตะ และคืนค่ากลับได้จากประวัติ
- **ข้อมูลและสถานะ (F1):** ดูว่างาน AI ทำอะไรอยู่ VRAM ของ GPU, Ollama เชื่อมต่อได้ไหมและโมเดลไหนอยู่ใน VRAM, ไฟล์โมเดลครบไหม, เวอร์ชันซอฟต์แวร์ และลิงก์เปิดโฟลเดอร์งาน/บันทึก error (รีเฟรชเองทุก 3 วินาที)
- ไฟล์ทำงานอยู่ที่ `work/<ชื่อโฟลเดอร์>/<ชื่อหน้า>/` (original, mask, cleaned, paint, final, page.json)
- ใส่ฟอนต์ `.ttf`/`.otf` เพิ่มได้ในโฟลเดอร์ `fonts/` แล้วเลือกใช้ในตั้งค่าหรือต่อกล่อง

## CLI
```
.venv\Scripts\python -m manga_translator.cli page.png --from ja --to th
```

## ติดตั้งเองทีละคำสั่ง (ถ้าไม่ใช้ setup.bat)
```
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu128
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m pip uninstall -y opencv-python opencv-python-headless
.venv\Scripts\python -m pip install opencv-python-headless==5.0.0.93
.venv\Scripts\python tools\download_models.py
```
ถ้าไม่มีการ์ด NVIDIA ให้เปลี่ยน `cu128` เป็น `cpu` ส่วน rapidocr จะดึง `opencv-python` (ตัวที่มี Qt) มาด้วย ซึ่งชนกับตัว headless จึงต้องถอนออกแล้วติดตั้งเฉพาะตัว headless

## ทดสอบ
```
.venv\Scripts\python -m pytest -q
.venv\Scripts\python tools\ui_smoke.py <โฟลเดอร์ภาพ> <โฟลเดอร์งานชั่วคราว> <screenshot.png>
```
เทสต์ใช้หน้ามังงะสังเคราะห์จาก `tests/synth.py` ไม่ต้องใช้ภาพที่มีลิขสิทธิ์ เทสต์ `test_real_ollama` จะข้ามเองถ้าไม่ได้เปิด Ollama
